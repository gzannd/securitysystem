ESP32 Device Manager - URL Parameters Test

This page demonstrates how to use URL parameters to pre-populate device information in the ESP32 Device Manager.

URL Parameter Format

The following parameters can be passed via URL query string:

index.html?deviceName=DeviceName&macAddress=MAC:AD:DR:ES:S0:00&firmwareVersion=v1.0.0&uptime=3600&wifiStatus=Connected&ipAddress=192.168.1.100

Parameter Details:

  • deviceName - User-defined device name
  • macAddress - Device MAC address (format: XX:XX:XX:XX:XX:XX)
  • firmwareVersion - Current firmware version
  • uptime - Device uptime in seconds (integer)
  • wifiStatus - WiFi connection status (e.g., "Connected", "Disconnected")
  • ipAddress - Device IP address

Example Usage in ESP32 Code

// Redirect to device info page with parameters String redirectUrl = "/index.html?"; redirectUrl += "deviceName=" + urlEncode(deviceName) + "&"; redirectUrl += "macAddress=" + WiFi.macAddress() + "&"; redirectUrl += "firmwareVersion=" + urlEncode(FIRMWARE_VERSION) + "&"; redirectUrl += "uptime=" + String(millis() / 1000) + "&"; redirectUrl += "wifiStatus=" + urlEncode(WiFi.status() == WL_CONNECTED ? "Connected" : "Disconnected") + "&"; redirectUrl += "ipAddress=" + urlEncode(WiFi.localIP().toString()); server.sendHeader("Location", redirectUrl); server.send(302, "text/plain", "");
